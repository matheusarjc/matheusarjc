## Como eu penso Produto

Para mim, produto não é apenas backlog, tela bonita ou lista de funcionalidades.

Produto é a combinação entre:

> **Problema certo + usuário certo + solução viável + modelo sustentável + execução bem priorizada.**

Antes de pensar em construir, gosto de entender:

* Qual problema estamos resolvendo?
* Para quem esse problema é realmente relevante?
* Qual comportamento queremos mudar ou facilitar?
* Como essa solução gera valor para o usuário?
* Como esse valor se conecta ao resultado do negócio?
* O que precisa ser medido para sabermos se estamos evoluindo?

Acredito que bons produtos nascem quando existe equilíbrio entre **visão, evidência, execução e aprendizado contínuo**.

## Como eu me comporto trabalhando

Sou uma pessoa orientada a clareza, responsabilidade e execução.

No dia a dia, costumo atuar como alguém que organiza o caos, conecta áreas e transforma ideias soltas em direção prática para o time.

Meu comportamento profissional é guiado por alguns princípios:

### 1. Clareza antes de velocidade

Acredito que acelerar sem entendimento costuma gerar retrabalho. Antes de correr, gosto de garantir que o time entenda o problema, o objetivo, as restrições e os critérios de sucesso.

### 2. Produto precisa conversar com negócio

Uma funcionalidade só faz sentido quando existe uma relação clara com geração de valor: aquisição, ativação, retenção, receita, eficiência operacional, satisfação do cliente ou redução de risco.

### 3. Engenharia precisa estar próxima da decisão

Não gosto de tratar tecnologia como etapa final. Times técnicos precisam participar cedo das decisões para evitar soluções inviáveis, caras, frágeis ou desnecessariamente complexas.

### 4. Usuário não é hipótese decorativa

Gosto de olhar para comportamento, dores reais, objeções, fricções e contexto de uso. Produto bom não nasce apenas do que o time acha elegante, mas do que o usuário entende, adota e valoriza.

### 5. Simplicidade é uma decisão estratégica

Nem todo produto precisa nascer complexo. Muitas vezes, o melhor caminho é reduzir escopo, validar rápido, medir bem e evoluir com consistência.

### 6. Métricas precisam orientar, não maquiar

Gosto de trabalhar com métricas que ajudem o time a decidir melhor, não apenas números bonitos para apresentação. Métricas boas mostram avanço, gargalos e oportunidades de melhoria.
